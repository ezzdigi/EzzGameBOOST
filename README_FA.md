# EzzGameBOOST — پروژه اندروید

نسخه اولیه قابل بازکردن در Android Studio با Kotlin و رابط کاربری مشکی/قرمز.

## امکانات فعلی
- داشبورد گیمینگ با برند EzzGameBOOST
- تست زمان اتصال TCP به `1.1.1.1:443` (این مقدار پینگ ICMP یا پینگ داخل بازی نیست)
- فهرست برنامه‌های قابل‌اجرا و اجرای آن‌ها از لانچر
- میان‌بر تنظیمات نمایشگر و باتری
- بدون روت و بدون ادعای بستن اجباری برنامه‌های دیگر

## ساخت APK
1. فایل ZIP را استخراج کنید.
2. Android Studio را باز کنید و گزینه **Open** را بزنید؛ پوشه `EzzGameBOOST` را انتخاب کنید.
3. اجازه دهید Gradle Sync کامل شود. در صورت درخواست، Android SDK Platform 35 و JDK 17 را نصب/انتخاب کنید.
4. از مسیر **Build > Build Bundle(s) / APK(s) > Build APK(s)** خروجی بگیرید.
5. APK معمولاً در مسیر `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## محدودیت‌های اندروید
اپ‌های عادی اندروید اجازه ندارند پردازش برنامه‌های دیگر را آزادانه ببندند، فرکانس CPU/GPU را کنترل کنند یا FPS و پینگ بازی را تضمین کنند. این نسخه ابزارهای امن و میان‌برهای سیستمی را ارائه می‌کند. تست شبکه، زمان اتصال TCP را اندازه می‌گیرد و ممکن است با پینگ داخل بازی متفاوت باشد.
